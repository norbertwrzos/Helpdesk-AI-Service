# Frontend — Helpdesk AI Service

Frontend aplikacji oparty na React + TypeScript + Vite.

## Uruchomienie

```bash
npm install
npm run dev
```

Frontend dostępny pod: http://localhost:5173

## Build produkcyjny

```bash
npm run build
npm run preview
```

## Proxy API

Vite proxy przekierowuje wywołania `/api/*` → `http://localhost:8000`.
